# Drill Notebook v0.8.2 预发行说明

- 版本：`v0.8.2`（Pre-release）。
- 准备日期：2026-11-15。
- 发行产物：`Drill-Notebook-0.8.2-win-x64-portable.zip` 及对应 `.zip.sha256`，Windows x64，解压后运行 `Drill Notebook.exe`。
- 本文记录发布准备，实际发布时间及下载附件以对应标签的 [GitHub Release](https://github.com/qilin-software/drill-notebook/releases) 为准。

## 主要变化

- **笔记混合检索接入助手**：`search_materials` 默认结合关键词与可选向量检索，支持自然语言查询、笔记本范围、相关片段与真实来源。同页结果合并、重复片段去重。精确名称、编号和原文仍可使用关键词模式，需要前后文时按 ID 分段读取。未配置向量或向量暂不可用时使用 BM25。
- **联网搜索与网页读取**：新增 `search_web` / `fetch_web`，免配置的「内置自动」默认开启。搜索优先使用 Exa 匿名 MCP，受限时有界尝试 Tavily Keyless。网页读取优先在本机提取公开网页正文，必要时使用备用服务。结果提供可引用来源，受现有工具权限、运行预算与停止操作约束。
- **联网服务配置与快捷开关**：在「设置 → 工具」分别选择搜索、网页读取服务，首批支持 Tavily、TinyFish，可保存配置与测试连接。助手输入栏的地球按钮快速启停联网，并跨会话、重启保存。可启用「优先使用模型内置 Web 工具」，按官方连接与模型能力使用 OpenAI / Anthropic 原生联网。
- **原地重试与会话独立选模**：「重试 / 重新生成」复用原提问、附件、轮次与回答位置，重试较早轮次时仅使用截至该轮的上下文。每个会话分别记住自己的供应商、模型与思考档位，新会话继承最近选择，改选不会覆盖其它会话或正在运行的任务。
- **上下文占用与累计用量分开统计**：输入栏圆环和「上下文总量」使用最后一次实际主模型请求及其响应的快照，输入、输出、缓存命中 / 未命中与命中率统计整个会话的累计用量，包含工具往返、自动恢复和原地重试。修正不同供应商缓存口径，缺失数据保持未知或下界。
- **上下文详情**：「查看上下文详情」展示当前请求的模型与窗口占用，并按实际请求查看规则、历史、资料、工具定义、调用参数和结果等组成估算，支持前次请求对比与更早请求分页。切换查看历史请求时，顶部当前占用卡片继续显示最后请求快照。
- **助手交互修正**：来源链接可直接在默认浏览器打开，悬停可查看目标网址。修正会话重命名回车确认后的多余焦点框，以及输入框多出一行的布局问题。

## 升级与数据

1. v0.8.0 及之后版本可在「设置 → 关于」检查更新，或使用已开启的自动更新。手动升级时先退出旧版并备份完整便携目录，再替换程序。保留 `data/`、`config/`、模型、附件和 `backups/`。
2. 本版数据库升级至 **schema 21**：新增联网服务配置、原地重试回执与会话选模修订号，并补齐请求组成摘要与缓存口径。沿用升级前快照和未来版本拒绝机制，已有学习资料、会话、记忆与配置继续保留。回退旧版时恢复升级前备份，勿直接使用已升级数据库。
3. 已有会话保留独立模型选择，旧空选择优先匹配最近实际使用的模型，无法唯一匹配时初始化为当前默认。新会话继承最近选择，已受理任务继续使用原配置。
4. 笔记向量来源仍须用户主动配置，不自动下载模型，远程 embedding 沿用授权要求。联网仅发送必要查询或目标公开 URL，不自动上传本地笔记、记忆或整段会话。服务密钥加密保存在便携数据库，配置、数据和临时文件继续落在 APP_ROOT。
